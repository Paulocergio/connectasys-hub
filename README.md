# ConnectaSys Hub

Preciso de um SaaS com o nome ConnectaSys. Será um sistema para gerenciamento de oficina mecânica. Neste primeiro momento, não é necessário backend nem banco de dados.

O sistema terá uma landing page com todas as informações e com 3 opções de preço. Os dados podem ser fictícios e mockados.

A cor de fundo da aplicação deverá ser #121019.

Quando eu fizer login, preciso que haja verificação se o usuário está autorizado ou não a acessar o sistema.

Também preciso de uma aba para o usuário fazer o seu cadastro, já que a aplicação será multitenant.
